# Goal Rush

Goal Rush is a football-themed mental maths game featuring penalty shootouts, times tables, goalkeeping, number-line passing and a free-kick physics lab. Progress and collected stickers are saved locally in the browser.

## Play

[Play Goal Rush on GitHub Pages](https://herby9000.github.io/herbyprojects/goal-rush/)

## Local use

Serve the repository root with any static HTTP server, then open `/goal-rush/` in a browser. The app has no build step. A network connection is only used for the optional Google Fonts; system fallbacks preserve gameplay when offline.
